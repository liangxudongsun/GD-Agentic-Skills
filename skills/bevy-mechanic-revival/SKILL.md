# Bevy revival mechanic (docs-first stub)

Not a full port. Docs-first stub. Godot counterpart: godot-mechanic-revival.

## When to use

Load this when an actor is downed, can be revived, or respawns.

## ECS shape

- **Components:** a downed flag and a revive elapsed you define.
- **Resources:** run-wide tables live in a resource (bevy-data-resources), not an autoload.
- **Systems:** mutate those components on `Update` or the fixed timestep. Use `.chain()` when damage must land before death.
- **Messages:** one-shot facts (hit, pickup, quest advance) go through bevy-events-messaging. This file does not add a new event type name.

## Godot idea to Bevy idiom

| Idea | Bevy idiom (idea only) |
| --- | --- |
| Downed | A state or component flag via bevy-state-machines. |
| Revive progress | Elapsed on a component while an ally overlaps. Overlap is a spatial-query gap. |
| Respawn point | A stored transform. No checkpoint type was opened. |

## Gaps

- No downed, revive, or checkpoint type exists in Bevy.
- Overlap tests share the physics solver gap.

## NEVER

- No Godot node, resource, or signal types for this mechanic.

- No Godot types in Bevy code.
